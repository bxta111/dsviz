# DSViz — 数据结构可视化学习助手

> 与 AI 共创 · 个性化学习助手 · 实践大作业

## 项目简介

DSViz 是一个面向数据结构课程的**个性化学习助手**，专为偏好**视觉化理解**和**动手实操**的学习者设计。通过 DeepSeek 大模型驱动，构建了"讲解 → 练习 → 纠错 → 强化"的完整学习闭环。

## 学习问题建模

项目识别了数据结构学习中的三大核心瓶颈：

| 瓶颈类型 | 具体表现 | 本系统的解决方案 |
|----------|----------|-----------------|
| **概念混淆** | 栈(LIFO)和队列(FIFO)分不清、树和图混淆 | Canvas 可视化并列展示 + AI 引导区分关键特征 |
| **推理断层** | 理解递归但不理解递归如何作用于树遍历 | 逐步动画展示遍历过程（前序/中序/后序/层序） |
| **不会迁移** | 学了多种数据结构但不会根据场景选择 | AI 规划者根据掌握情况推荐学习路径 |

## AI 参与机制

AI 在系统中扮演四个明确角色，各有触发条件和交互策略：

| 角色 | 触发条件 | 职能 |
|------|----------|------|
| 🧑‍🏫 **讲解者** | 用户选择知识点 | 结合可视化画布讲解概念、复杂度、应用场景 |
| ❓ **提问者** | 讲解完成后自动触发 | 生成递进式题目（记忆→理解→应用） |
| 🔧 **纠错者** | 用户答错时触发 | 分类错误（计算错/理解错/方法错），针对性反馈 |
| 📋 **规划者** | 完成学习后触发 | 基于进度和掌握度推荐下一步学习路径 |

**状态驱动策略**：连续答对 → 提升题目难度；连续答错 → 重新讲解，换一种方式解释。

## 学习闭环

```
选择知识点 → AI讲解 + 可视化演示
     ↓
AI 提问，验证理解
     ↓
用户回答（选择/文字输入）
     ↓
AI 分析错误类型 → 针对性反馈
     ↓
强化练习 → 确认掌握 → 规划下一步
```

## 错误建模

系统能够区分三种错误类型并给出不同风格的反馈：

- **计算错 (Calculation)**：展示完整计算过程，指出是哪一步出错
- **理解错 (Understanding)**：用类比和可视化重新解释概念
- **方法错 (Method)**：展示正确方法和错误方法的对比

## 可扩展性

- **知识点数据分离**：`topics.js` 中所有知识点以配置形式定义，新增只需添加配置对象
- **Prompt 模板化**：AI 角色 Prompt 使用参数化模板，自动适配不同知识点
- **可视化通用化**：Canvas 组件支持 array/nodes/stack/queue/tree/graph/hash 多种模式
- **练习题模板**：内置题库 + AI 动态生成双重保障

## 技术实现

- **纯前端**：HTML + CSS + JavaScript（零依赖，无需构建工具）
- **Canvas 可视化**：支持数组、链表、栈、队列、二叉树、图、哈希表的交互式渲染
- **DeepSeek API**：兼容 OpenAI Chat Completions 格式
- **localStorage**：学习进度本地持久化
- **部署**：可直接部署到 GitHub Pages

## 表达与反思

### AI 在哪些地方有效？

1. **概念讲解个性化**：AI 可以根据学生的历史学习记录调整讲解策略，比如对已经掌握数组的同学，讲链表时可以直接用数组做对比
2. **即时纠错反馈**：传统学习中做错题要等老师批改，这里 AI 即时分析错误类型，比"只看标准答案"更深入
3. **动态难度调整**：AI 根据学生连续表现调整题目难度，避免了"一题定难度"的僵化

### AI 在哪些地方效果有限？

1. **可视化同步不够精准**：当前 AI 只能生成文字讲解，可视化动画是预制的，无法完全和 AI 讲解内容同步——AI 说"现在插入节点3"，画布不会自动跟着动
2. **对复杂错误的判断有偏差**：AI 对"理解错"和"方法错"的区分不是 100% 准确，偶尔会把方法错归类为理解错
3. **依赖网络**：AI 功能需要稳定的 API 连接，离线环境下只能使用内置题库降级

### 与传统学习方式的差异

| 维度 | 传统学习（教材+课堂） | DSViz + AI |
|------|---------------------|-----------|
| 讲解方式 | 统一讲解，所有学生一样 | 根据学习风格（视觉+操作）调整讲解 |
| 练习反馈 | 对答案，错了看解析 | 分类错误类型，针对性纠正 |
| 学习节奏 | 按课表统一推进 | 自适应难度，掌握才解锁后续内容 |
| 可视化 | 教材上的静态图 | Canvas 交互式动画，可操作 |
| 学习路径 | 固定顺序 | 动态推荐，基于掌握情况 |

### 可改进方向

1. 增加语音输入/输出，让交互更自然
2. 可视化动画与 AI 讲解内容的实时同步（让 AI 能控制画布）
3. 增加代码实操区（IDE 沙箱），让学生真正写数据结构代码
4. 多人协作学习功能

## 快速开始

1. 打开 `index.html`（推荐使用 Live Server）
2. 点击右上角 ⚙️，填入 DeepSeek API Key
3. 从左侧导航选择一个数据结构主题
4. AI 开始讲解，跟着流程学习！
